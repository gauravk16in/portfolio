## Projects

### MCPDASH

A testing and debugging tool for MCP servers with live traffic inspection, session restore, and workflow visibility.

Built with React.js, TypeScript, Node.js, and WebSocket, MCPDASH lets developers connect to MCP servers, inspect tools, resources, and prompts, and monitor live traffic in a console-style UI. IndexedDB-backed session storage restores the last session after refresh, while cursor-based pagination and replay make previous tool calls easier to inspect and debug.

The project also includes plans for an stdio proxy recorder and a schema change detector to make MCP workflow debugging more reliable and developer-friendly.

**Tech:** React.js, TypeScript, Node.js, WebSocket, IndexedDB, MCP

### Receipts

A CLI-based GitHub memory tool that tracks public statements and project history to detect contradictions and evaluate proposed changes against maintainer preferences.

Built with TypeScript, Node.js, MCP, and Supermemory Local, Receipts helps check proposed codebase changes against repository contribution guidelines, project history, and maintainer expectations. The goal is to reduce inconsistency in open-source workflows and improve confidence before fixing issues or opening pull requests.

**Tech:** TypeScript, Node.js, MCP, Supermemory Local, CLI, GitHub tooling

### Sipify Ads Creative

An AI studio interface for smoother creative workflows, with backend integration and MCP compatibility.

Built using React, TypeScript, FastAPI, ElevenLabs, MCP, and Postman, this project focused on improving the Sipify AI studio interface, strengthening the UI/UX, and integrating key backend workflows for a smoother product experience. It also includes an MCP server for connecting Sipify with compatible MCP clients and expanding integration support.

**Tech:** React, TypeScript, ElevenLabs, MCP, Postman, FastAPI

### FindTogether

A prototype platform for families to find lost loved ones using similarity scoring across missing and found-person cases.

Built with React.js, Node.js, Supabase, and Figma, FindTogether compares cases using description, location, and time, and presents the results through a real-time dashboard with a prioritization flow. The project was selected at the institute level for Smart India Hackathon 2025, where it was led as a team project.

**Tech:** React.js, Figma, Node.js, Supabase, Similarity Scoring, Real-time Dashboard

### Location Price Bangalore

A Bangalore real-estate discovery platform that combines project listings with locality-based market insights for easier comparison.

Built with HTML, CSS, JavaScript, and Figma, the platform helps users explore properties with both listing data and locality-level market context, making project discovery and comparison more informed.

**Tech:** HTML, CSS, JavaScript, Figma
